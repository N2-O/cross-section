Cross-Section 更新说明
======================

怎么更新
--------
从 GitHub Releases 下载新版本的整包，解压后替换旧的程序文件：

    https://github.com/OWNER/cross-section/releases

替换时只覆盖程序本身（START.bat / check.bat / cs2tool\ 目录等），
**保留 data\ 和 demos\** 两个目录 —— 那里是数据库和你拉下来的原始 demo，
覆盖掉等于所有统计重来一遍。


会不会自动提醒
--------------
会。打开面板时会在后台问一次 GitHub 上最新的 Release（24 小时最多问一次），
版本号旁边如果出现绿色的 **NEW** 徽章，就说明有新版了：

  · 点 NEW 徽章 → 直接打开那一版的发布页
  · 点版本号本身 → 打开全部发布列表

这个检查只发一个匿名请求，不带任何本机信息，失败时静默跳过，
断网也不影响使用。


更新完没生效？
--------------
1. 必须重启 START.bat，Python 不会热加载
2. 浏览器按 Ctrl+F5 强刷，否则会用缓存的旧页面
3. 确认替换的是 cs2tool\ 目录里的文件，而不是又解压到了别处


旧机制（已停用）
----------------
v6.1 之前的 update.py / update.bat（把新包改名成 update.zip 再跑增量覆盖）
已经停用，文件留在 _archive\ 里只作留档，不要再用了 ——
GitHub 上下的整包直接替换更省事，也不会因为 md5 对比出错搞出半新半旧。
