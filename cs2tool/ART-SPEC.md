# Cross-Section 美术与界面规范

> 版本 v1.0 · 2026-10-22
> 这份文档是**约束**，不是建议。改任何界面之前先对照它，有冲突的地方要么改代码服从规范，要么先改规范并说明理由。
> 定这套东西的原因：`replay.html` 曾经是分十几轮补丁堆出来的，最后有 19 种字号、19 种硬编码颜色、3 种圆角混用——看着「都不算错」但整体不协调。规范的作用是让新增的东西天生就对齐。

---

## 1. 色板

### 1.1 阵营色（唯一允许的高饱和色）

| 用途 | 值 |
|---|---|
| CT | `#5b8fd4` |
| T | `#d8a83c` |

**阵营色跟着「当前这只是哪一边」走，不是跟着「我方/敌方」走。** 换边后颜色自动对调，同一张图里不能用「我方/敌方」当图例词——那会在换边后的回合里指代两个不同的阵营。

### 1.2 中性色阶

| 角色 | 值 | 用在哪 |
|---|---|---|
| 主文本 | `#e8e8e9` | 数值、标题、当前项 |
| 次文本 | `#c9c9cc` | 次要数值、图例文字 |
| 弱文本 | `#8a8a8e` | 单位、注脚、未选中 |
| 更弱 | `#6f6f73` | 坐标轴刻度、时间戳 |
| 分割线 | `#2c2d2f` | 表格行线 |
| 面板底 | `rgba(9,9,11,.46)` ~ `.50` | 卡片/面板，**必须带 `backdrop-filter:blur(10~12px)`** |
| 悬停底 | `rgba(255,255,255,.028)` | 表格行 hover |
| 轨道底 | `rgba(255,255,255,.055)` | 柱状图槽、进度条底 |

### 1.3 状态色（少量、有语义才用）

| 用途 | 值 |
|---|---|
| 正 / 胜 | `#7bd44b` |
| 负 / 败 | `#e05555` |
| 警示 | `#ffcf3a` |
| 平局 / 未知 | `#8a8a8e` |

### 1.4 禁止

- ❌ **同一屏出现 3 种以上高饱和色**。图表里除了阵营色，其余全部走中性色阶。
- ❌ 用 `#ffd166` / `#b98bff` 这类「额外好看的颜色」当图表系列色。曾经 5 种亮色同屏，结论是「过于鲜艳失衡」。
- ❌ 蓝灰（B-R ≥ 5）的界面色。除阵营色外，R≈G≈B。

## 2. 字号

四档，不许新增：

| 变量 | 值 | 用在哪 |
|---|---|---|
| `--f-hero` | 27px | 只在概览主读数（Rating 级别） |
| `--f-big` | 21px | 分节大数字 |
| `--f-mid` | 13px | 正文、表格、按钮 |
| `--f-cap` | 11px | 标签、单位、注脚 |

第五档（仅限小卡片里的读数，如道具面板、指标格）：

| 值 | 用在哪 |
|---|---|
| 17px | 卡片内的数值（`$4,363`、`16 颗`）。卡片小、行多，用 21px 会撑爆，用 13px 读不清 |

补充：
- **图表内文字** 9–10.5px 可接受（SVG 里），但**正文任何地方不得低于 10.5px**。
- **数字一律无衬线 + `font-variant-numeric:tabular-nums`**；中文文字用衬线。数字是读数，文字是语气。
- **读数写完整数字 + 千分位**（`813,963`），不用 `81.4k` 或科学计数法。仅坐标轴刻度可缩写。

---

## 3. 形状

| 项 | 规定 |
|---|---|
| 圆角 | **一律 0 或 3px**。不允许 6/8/10/12px 混用。卡片、按钮、图表柱、高亮块全部走直角 |
| 边框 | 面板默认**无边框**，靠底色 + 透明度分层；必须有线时用 `1px #2c2d2f` |
| 阴影 | 只在弹层/抽屉用，且是**矩形投影**（`0 -18px 48px rgba(0,0,0,.6)`），**禁止圆角矩形阴影** |
| 装饰条 | 没有信息量的白条、横线、分隔装饰一律删掉 |

---

## 4. 布局

- **版心 1760px**，不收横向滚动条。
- **左右留白**：内容块之间不顶满。表格/图表在容器内再收一层（`padding` 24~36px 或 `max-width`），"面板变窄但表格仍顶满"是没效果的。
- **左侧定宽、右侧自适应**。不做左右等分的对称谜题（除非内容真的一一对应）。
- 面板开关收在边缘或侧栏；关闭按钮用低调的 `×`。
- 尽量不出现滚动条。必须有的时候自定义样式，能换行/换形态就换（`‹ 名字 ▾ ›` 选单替代一排 tab）。
- 分节编号用悬挂式（`left:-30px`、13px→19px 标题），序号比正文略向左溢出。

---

## 5. 图表

| 项 | 规定 |
|---|---|
| 画布 | **固定尺寸**（如 `1180×380`），回合数变化时格宽反算，**面板尺寸不跟着波动** |
| 柱 | 阵营色实心、直角。单值柱顶标数字 |
| 线 | **中性灰** `rgba(232,232,233,.55)`，1.8px，节点 2px 圆点（当前点 3.4px + 白色） |
| 标注 | **常显，不只 hover**。字号 9–10.5px，与背景对比不足时加 `stroke` 描边垫底（`paint-order:stroke`、`stroke-width:2.6~2.8`） |
| 数值位置 | 柱端标具体值；差值标在**远离中线的一侧**，避免 0 轴附近和柱值重叠 |
| 图例 | 必须有，且用**语义名**（CT 总经济 / T 总经济），不用「我方/敌方」 |
| 空状态 | 居中显示 `—` 或提示语，不贴左上角 |
| 样本不足 | 显示 `—`，**不显示 0** |

---

## 6. 表格

- 数字列**右对齐** + tabular-nums；文字列左对齐。
- 列宽固定或按内容分配，**不平均分配**填满宽度。
- 单元格多时优先**换行 / 收窄列**，不横向滚。
- 表格在卡片内有左右 padding，不贴卡片边缘。
- 悬浮说明默认隐藏，悬浮标题才显示；设置里有总开关。

---

## 7. 交互

- **所有动画双向**：出现和消失都要有过渡，消失要经过 `closing` 中间态再卸载。硬切 = 不丝滑。
- 侧栏切换用 `transition` + 内部淡出。
- 拖拽控件（滑块）的圆点和轨道**必须垂直居中**：`margin-top: -(thumb - track)/2`。刻度常显在下方。
- 按钮文案用中文，不用 emoji 当导航。
- 数据面板按钮能省则省，键盘（Tab）能开就用键盘。

---

## 8. 背景与特效

- 深色底衬保留。背景图/烟雾/阵营色/剪影保留，但**必须压暗**（`mix-blend-mode:multiply`），不是提亮。
- 文字区域要 `rgba(9,9,11,.5)` 底 + `blur`，否则字看不清。
- 背景动效只放前景（弹痕、尾流），背景本身随滚动固定不动（`background-attachment:fixed`）。
- 大图剪影做水印：**等高、贴右上、允许溢出**，不要为了塞进去而缩放或居中。

---

## 9. 改动前的自检

1. 新加的颜色，能不能用上面已有的？不能的话，是真的需要，还是只是想好看？
2. 新加的字号，是不是已经在四档里？
3. 圆角是不是 0 或 3px？
4. 表格/图表是不是又顶满了？左右留白了吗？
5. 数值有没有千分位？有没有被缩写成 `12k`？
6. 图例说的是「CT/T」还是「我方/敌方」？
7. 固定尺寸还是随数据波动？
8. 数字有标注还是只能 hover？
