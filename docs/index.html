CS2 的 .dem 里记着一整场比赛的每个 tick。它同时是一份完整的账本——谁在第几回合买了什么、哪一枪打在哪里、谁在残局里活了下来。Cross-Section 把这个账本翻成能看的东西，只给你自己看。

02

切开来能看见什么

每个指标都能悬浮看公式
Overview

概览与逐场趋势

Rating 2.0、ADR、KAST、Impact、K/D、首杀率、补枪与拉枪占比。一场一场排开，看的是曲线，不是孤立的数字。

Ability

能力画像

从击杀、生存、残局、多杀这些事件里反推出的分维能力——长什么样、在变好还是在变差。

Weapons

武器明细

每把枪的击杀数、命中率、爆头率、每击杀耗弹。不是猜哪把枪手感好，是有数。

Clutch

残局与多杀

1v1 到 1v5 全部重建出来。awpy 的 clutch 字段是空的，这里按击杀事件流自己数存活人数。

Economy

经济与道具

每回合经济差、购买类型分档、起枪节奏；闪光致盲时长、烟雾与燃烧的覆盖与伤害。

Replay

回合级回放

四栏 HUD + 地图雷达 + 双轨回合轴。想再看一遍那个残局，不用回游戏。

03

使用说明

与下载包内的 README.md 一致
01

解压

把 zip 解压到任意目录。不需要安装 Python，运行时已包含在 python/ 目录内。

02

启动

双击 START.bat。浏览器会自动打开 http://127.0.0.1:8790。

03

放入录像

把 .dem 放进 demos/；或在 Demo 页点「⇩ 从 CS2 拉取」从游戏目录自动复制；也可把目录指向同步盘。

04

分析

打开 Demo 页 → 点「分析未处理」。一场约 8–15 秒，进度条走完即可。

05

看数据

回主页。顶栏下拉可切换「我是谁」：工具按跨场出现次数自动推断，认错时手动选一次，之后会记住。

06

更新

有新版本时版本号旁会亮起 NEW，点它进入发布页。下载新包覆盖安装，保留 data/ 与 demos/。

数据位置：data/cs2.db 一个 SQLite 文件即为全部统计，拷走即是备份。首次启动会自动创建 demos/ 与 data/；删除整个程序目录即清除，注册表与 AppData 不留任何内容。

能读哪些录像
Cross-Section 读的是 CS2 标准的 .dem 文件。官方匹配的录像已实测；5E 与完美世界下载下来的录像也是同一套封装，理论上可以直接解析，但我们还没有实测过——解析逻辑没有针对任何平台做特殊处理，能不能跑通取决于那份录像本身是不是标准的 CS2 demo。

5E / 完美世界 ·· 同一格式，待验证

如果你的第三方平台录像解析失败，把 demo 的文件头信息和报错贴到 Issue，比什么都管用。

分发渠道：只在 GitHub Releases 发布。其他站点、网盘、群里转的包都不是这里发的，无法确认有没有被改动过。
04

它不碰你的游戏

只读磁盘上的 .dem 文件

不读游戏进程、不注入、不修改任何游戏文件。它跟 CS2 客户端之间没有交互——不读内存、不 hook、不改文件，所以不存在接触面。但账号状态不由它保证，反作弊策略也不由它控制。

也不上传。程序只会发一个 GET 去 GitHub 公开 API 问「最新版本号是多少」——不带任何本地数据、不带 cookie、不含设备标识，返回结果只用来在版本号旁边显示一个 NEW。除此之外不往外发任何东西。

数据全部落在一个 SQLite 文件里。删掉程序目录就干净了——注册表、AppData、我的文档，什么都没有。
